# Joseph: Dreams of Egypt

An original browser arcade game with Egyptian scenery, colourful characters, glittery microphone and banana throws, and an original synthesised soundtrack.

Open `index.html` in a browser to play locally. Keep `enhancements.js` beside it. Sound starts after pressing Play.

## Hosting

The GitHub Actions workflow publishes the game on pushes to `main`. In repository Settings → Pages, choose GitHub Actions as the source.

This is an independent game concept, not an official production website. No theatre branding or recordings from the musical are included.
